# トラックシート

Suno で曲を作るときの補助アプリです。ブラウザで `index.html` を開くだけで動きます（サーバー不要）。

## できること

- **MIDI から作る**: .mid ファイルを読み込むと、テンポ・拍子・長さ・推定キー・各トラックの役割（音域と和音の数から推定）・小節ごとのコード・曲の区切りを分析し、Suno 用の構成タグ（盛り上がり・音色・小節数・コード進行つき）とスタイルの言葉に変換。トラックごとに Suno での音色を選べる。音のタイミングが拍に合っていないファイル（録音や音声から変換した MIDI）は、ドラムや音の間隔から実際の BPM を推定して小節を組み直す。トラック数が少なく編成が変わらない曲は、コード進行の似たまとまりから Aメロ・サビ・Cメロを見分ける。後半の転調も検出し、「時間メモに書き出す」で流れを日本語のメモにできる。小節ごとのコード表（セクション別・時間つき）を表示し、簡易音（トラックの音色に合わせたノコギリ波・矩形波など、ドラムも合成音で再生、音量調整つき）で再生しながら今の小節を光らせて進行を追える。ファイルはブラウザの中だけで読み、外部に送らない。
- **音ゲーのジャンル図鑑**: ピアノハウス、フィルターハウス、クロスオーバーハウス、ドリームトランス、メロディックDnB、スウィングワルツ、ピアノのワルツ、テックダンス、サイバーリキッドファンク、80年代シンセファンク、アシッドジャズ、インダストリアルベース、ハードテクノ、ダブステップ、サイトランス、ハッピーハードコア、70年代ディスコ（生演奏）、ディスコ・ファンク（ホーン）、和風テクノの19ジャンルを、Suno 用の言葉にしたプリセット。
- **組み合わせセット**: 「田中秀和風アイドル × クラブ」「カオス☆パイセン（畑亜貴風 × aug 進行）」「モヤモヤ退散☆パイセン（癒し × aug 進行）」「ゴシック騎士譚（オーケストラ × BPM200・全部英語）」「80年代クラブ（イタロ・ハウス × Hi-NRG・単純な英語）」「2000年代レースゲーム × ハウス」「80年代クラブ × アーバン（R4 風）」「ハイパーユーロビート × スピードレイヴ」「ハンズアップ × 音ゲー（スーパーソー）」「元気が出るスピードレイヴ」「EW&F 風ディスコ・ファンク」を押すと、スタイル・オリジナル歌詞（「ハレノチ☆ステージ」「カオス☆パイセン降臨祭」「モヤモヤ退散☆パイセン」「The Oath of Sir Aurelion」「Dance Into The Light」「Ride Until The Dawn」「City After Midnight」「Fading Starlight」「Skyward Rush」「Turbo Sunrise」「Golden Hour Groove」）（盛り上がり・小節数・コードのヒントつき、約1分50秒）・コード進行・歌詞のエッセンスまで入った曲を新しく作る。
- **イメージから決める**: 情景のイメージ・雰囲気を合わせたい曲・画像から、Claude がスタイル案を3つ提案（曲名やアーティスト名は使わず、ジャンル・年代・楽器・声質・音作りに置き換え）。「この案を使う」で STYLE に反映。夜のドライブ、夏祭り、決戦・バトルなど 13 種の情景プリセット付き。Claude を呼び出せない環境では、ほかの AI チャット用の指示文をコピーし、回答の JSON を貼り付けて使える。
- **スタイル組み立て**: ジャンル・ムード・ボーカル・楽器・サウンドをタップで選ぶと、Suno の「Style of Music」に貼る英語の文字列を自動で作成。BPM・キー・自由入力にも対応。
- **いちばん目立たせたい音**: 低音のベース・ピアノ・エレピ・ボーカル・ドラム・シンセのリード・スーパーソー・ホーン・ストリングスから選ぶと、スタイルの先頭に強い言葉（例: heavy deep bassline, bass-heavy mix）で入る。「各セクションのタグにも入れる」で全セクションに追加できる。
- **除外スタイル**: Exclude Styles 用の文字列をタップで作成。
- **歌詞エディタ**: `[Verse]` `[Chorus]` などのタグをワンタップで挿入（Verse は自動で番号付け）。J-POP 王道 / EDM / ヒップホップなどの構成テンプレ付き。
- **展開・緩急（DYNAMICS）**: セクションごとに盛り上がり（5段階）と演出（ドラム抜き、ハーフタイム、落ちサビ→全開、転調、一瞬止める など）を選ぶと、`[Chorus: explosive, key change up]` のようにタグへ書き込む。「王道の盛り上がり」「静と動」「落ちサビ→大サビ」「ラスサビ転調」「ためて爆発」の展開パターン付き。
- **感想 → プロンプト**: 参考曲を聴いた感想（例:「静かでひんやり」）を書くと、Claude が音色・楽器・リズム・ミックスの英語に置き換えて提案。構成（盛り上がり・小節数つきのタグ）も提案し、LYRICS に入れられる。「清涼感」「静寂」「クール」などの感想ワードを押すと英語の表現を STYLE に追加。
- **長さの目安**: セクションの小節数と BPM から曲の長さを推定。目標（2分以内など）を超えると表示し、「目標に収める」で小節数を自動で減らす。「音ゲー2分」テンプレ付き。
- **ハンズアップ型の盛り上がり**: ピアノのブレイクダウン → スネアロールで溜める → 主旋律を全開で戻す展開パターン、「ハンズアップ2分」テンプレ（149 BPM・約1分43秒）、情景プリセット「ハンズアップ」。
- **長さ対策**: 「短く終わる工夫を入れる」でイントロ・アウトロを4小節にして [End] を置く。SEND に Suno v5.5 の Duration スライダーに入れる長さの目安と、Crop Song で切る手順を表示。
- **コード進行（HARMONY）**: 王道進行・丸サ進行・小室進行・カノン進行に加え、aug クリシェ、aug の分数コード、半音で下りる、sus から解決、短3度上へ、哀愁ユーロ進行、サビ前で転調などの進行を、選んだキーの実際のコードで表示。進行の雰囲気を英語にして STYLE に足すほか、歌詞へ `[Chord Progression: ...]` として書き込める（実験的）。コードのマスを押すと和音が鳴り、「進行を再生」で順に鳴らせる（分散和音にも切り替え可）。主音を同じにしてメジャー・maj7・7・m7・sus4・aug などの響きを聴き比べられる。
- **アーケード音ゲー**: ハードルネッサンス系をもとにした情景プリセットと構成テンプレ（190 BPM・約1分41秒、スクラッチ・急停止・ピアノソロ・転調ラスト・キメで終わる）。除外にチップチューン・8bit・レトロゲームを追加。
- **時間メモ → 構成**: 「0:20 静かになってピアノだけ」のように時間と感想を書くと、BPM から小節数を計算して、盛り上がり・演出・音色つきのタグに変換（Claude で整えることも可）。メモに出てきた音を STYLE に足せる。情景プリセット「深海ハードルネッサンス」付き。
- **4つ打ち→サビでアーメン**: ふだんは4つ打ち、サビ（Drop）でアーメンブレイクに切り替え、溜めでライザー、アウトロで16分のノイズチョップを使う構成テンプレ（185 BPM・約1分49秒）。アンセム系リード・オク下重ね・ライザーなどの言葉と演出を追加。
- **アウトロは必ずフェードアウト**: オンにすると（初期設定はオン）、テンプレ・組み合わせセット・時間メモ・Claude の歌詞など、どこから歌詞を入れても最後を `[Outro: very soft, fade out]` → `[Fade Out]` → `[End]` にそろえ、STYLE に fade out ending を足す。手で書き換えた場合も、歌詞をコピーするときに自動で整える。
- **EDMっぽさを抜く**: Drop・Build-up のタグを Chorus・Break（ドラムフィル）に変え、explosive・riser・supersaw などの今風の言葉を外し、late 80s club record・vintage analog production などの言葉と、big room EDM・drops などの除外を足す。
- **効果音**: [Reverse Cymbal]、[White Noise Riser]、[Noise Burst]、[Glitch Stutter]、[Laser Zap]、[Crash Cymbal] などのタグと、reverse cymbal swells・white noise risers などのスタイルの言葉。MIDI の効果音トラック（GM 119〜127）も自動でこれらの言葉に変換し、再生ではノイズで鳴らす。
- **小節数はコピー時に外す**: Suno は小節数を正確には守らないため、Suno に貼るためのコピーではタグの「N bars」を自動で外す（アプリ内の長さ計算には使う）。残す設定もあり。
- **ネタ・煽り**: [Air Horn]、[Shout] Somebody scream!、[Riser]、[Rewind] などの効果音タグをワンタップで挿入。
- **構成チェック**: 歌詞からセクションを読み取り、Aメロ・Bメロ・サビの流れを帯で表示。歌詞のないセクション、日本語タグ、長すぎる行などを指摘。
- **文字数カウント**: v4.5 以降（スタイル 1000 / 歌詞 5000）と v4 以前（200 / 3000）の上限を切り替え可能。
- **日本語の歌モード**: オンにするとスタイルに `Japanese vocals`（女性・男性ボーカル選択時は `Japanese female vocals` など）を追加。「和・日本らしさ」カテゴリ（歌謡曲、渋谷系、三味線など）付き。
- **読みチェック**: 今日・空・辛い・瞬間など読みが複数ある漢字を検出し、選んだかなにまとめて置き換え。
- **作詞プロンプト**: テーマ・語り手・構成・1行の長さ・英語の量などを選ぶと、ChatGPT や Claude に Suno 用の日本語歌詞を書いてもらうための指示文を自動作成。
- **歌詞のエッセンス**: 夢とステージ、日常のときめき、言葉遊び・語呂、掛け声・コール、英語の決めフレーズ、一滴の切なさなどを選ぶと、その雰囲気で書くよう作詞プロンプトに入る。既存曲の歌詞は使わず新しく書くよう指示する。
- **語彙集め**: テーマから歌詞に使える言葉を Claude が30個集め、押した言葉を「入れたい言葉」に追加。エッセンスに「語彙たっぷり」「カオスな言葉遊び」を追加。
- **英語の歌詞**: 作詞プロンプトで「歌詞の言語」を「全部英語」にすると、英語で書く指示（1行の語数・音節をそろえる）に切り替わる。
- **Claude が作詞**: 作詞プロンプトの条件で Claude が歌詞とタイトル案を書き、確認・修正してから LYRICS に反映。
- **Suno に貼る**: Suno の Custom 画面の順（Lyrics → Styles → Exclude styles → Song Title）にコピーボタンを並べ、コピー済みの印を表示。Suno には公開 API がないため、生成は Suno の画面で行う。
- **保存**: 複数曲をブラウザ内に自動保存。JSON で書き出し・読み込み。
- **コピー**: 項目ごと、または全項目まとめてコピー。

※ 文字数の上限は Suno 側の仕様変更で変わることがあります。
